Features

Atox does one thing: it keeps your agents organized. Everything else stays the way your terminal already works.

Any agent

Claude Code, Codex or a plain shell. Atox finds the agents you have installed and starts the one you pick. Want different flags? Set your own launch command in Settings.

Real terminals

Every chat is a login shell in your project folder, not a wrapper around the agent. Colors, mouse, links and scrollback work exactly like in your terminal.

Agents team up

An agent can hand a task to another one — Claude can ask Codex for a review, and the result comes back as a message in the same chat. No "press yes" prompts on the way.

See every worker

Workers appear right under the chat that started them, with their agent's logo. The parent chat shows one status for the whole team, so the sidebar stays calm.

Projects and spaces

A project is a folder, its chats live inside. Group projects into spaces — work, side projects, clients — and jump between them with Ctrl+1–9.

Side by side

⌘-click (Ctrl-click on Linux) a chat to open it next to the current one and drag the divider to resize. Each project remembers its layout.

Know when it's done

A chat pulses while its agent works and turns blue when it finishes. Long tasks send a notification, so you can switch away and come back on time.

Keyboard first

New chat, next chat, find in terminal, font size, sidebar — all on shortcuts, and you can change any of them in Settings.

Mac and Linux

A native-feeling app on macOS and a single AppImage or Arch package on Linux, with Linux-style shortcuts that leave Ctrl keys to your terminal.

Lightweight

No indexing, no background services. An idle Atox stays under 1% CPU, and chats you haven't opened don't render at all.

Updates itself

When a new version is out, an Update button appears in the sidebar. One click, and Atox restarts on the new version.

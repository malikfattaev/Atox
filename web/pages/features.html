Features

Atox keeps your coding agents organized. They work exactly the way they do in your terminal, with their own tools and settings; Atox gives them a calm place to live.

Agents and models

Claude Code, Codex and other agents work in one chat. Pick the agent, the model and the effort right in the message box, and switch whenever you like: the new agent gets the conversation so far and picks up where the last one stopped.

Use the subscription you already have, or get models from an Atox plan.

Agent teams

An agent can hand a task to another one. Claude can ask Codex for a review, and the answer comes back as a message in the same chat. Workers appear right under the chat that started them, and the Agents page shows every running agent, with the ones that wait for you first.

Approvals and questions

When an agent needs permission to run a command or has a question, it shows a card in the chat and waits. Answer in one click, pick an option or type your own, and the agent carries on.

Changes and git

  • Changes panel: every file changed since the last commit, with its diff. Discard what you don't want.
  • Repository: commits, pull requests and issues of the project, right next to your chats.

Atox runs git in the background without getting in the way of agents' own commits.

Terminal

Every project has its own terminal in a panel next to the chat. Press ⌘ J to show or hide it; it keeps running while hidden.

Plan limits

How much of your Claude and Codex plans you have used stays in the sidebar, with the time until each limit resets. No more surprises in the middle of a task.

Projects and spaces

A project is a folder, and its chats live inside it. Give each project a color and one of 400+ icons, and group projects into spaces: work, side projects, clients.

⌘-click a chat to open it side by side with the current one, and drag the divider to resize.

Chats

  • Chats remember. Close Atox, come back, and every chat picks up where it left off, including drafts.
  • Queue messages. Send the next message while the agent is still working; it waits in line, and you can cancel it.
  • Know when it's done. A chat shows when its agent works, waits for you or finishes, and long tasks can send a notification.
  • Archive, don't lose. Archived chats leave the sidebar but keep their history, ready to restore.

Plugins, skills and MCP

See the plugins, skills and MCP servers your agents have in one place, without digging through config files.

Keyboard

New chat, next chat, terminal, sidebar and more are on shortcuts, and you can change any of them in Settings. Type / in the message box to see the agent's commands.

Light, fast, up to date

  • No indexing and no background services; an idle Atox barely uses the CPU.
  • A native-feeling app on macOS, and an AppImage or Arch package on Linux.
  • When a new version is out, Atox updates itself in one click.
  • Free and open source under the MIT license.

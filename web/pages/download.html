First launch

Atox isn't notarized by Apple yet, so the first time you open it macOS says it can't verify the developer. This happens only once:

  1. Open Atox and close the warning.
  2. Go to System Settings → Privacy & Security.
  3. Scroll down and click Open Anyway next to Atox.

Atox runs the agents you already have, so install at least one of them first — Claude Code or Codex.

Projects and chats

A project is a folder on your Mac. Click New project (⌘O) and pick a folder — Atox opens a first chat in it right away.

A chat is a terminal in that folder with an agent running in it. Create one with New chat (⌘N) and choose the agent. Chats are named after what the agent is doing; double-click a chat to give it your own name.

  • Drag projects and chats to reorder them.
  • Right-click a project to open it in Finder, copy its path, change its color, move it to another space or remove it from the list. The folder itself stays on disk.
  • The current git branch is shown under each chat.
  • Drop files or paste a screenshot into a chat — the agent gets their paths, just like in Terminal.

Agents

Atox detects which agents are installed and offers them when you create a chat. The one you pick becomes the default for ⌘N. You can always start a plain Terminal chat as well.

To start an agent with your own flags, set its launch command in Settings → Agents, for example claude --model opus.

Agent teams

Agents in Atox can delegate. Ask Claude to “have Codex review this” and it starts Codex in a new chat with the task. When Codex is done, its report arrives in Claude's chat as a new message, and Claude carries on.

Workers show up under the chat that started them as a collapsible “N agents” group. You can open any worker to watch it or step in. Ask the agent to remove workers you no longer need — for example, one it started by mistake.

Agents do this with the atox command, which is available in every Atox terminal. Claude Code and Codex learn it automatically; you can also use it yourself:

atox agentsList installed agents
atox start <agent> "<task>"Start a worker with a task
atox workersList your workers and their state
atox send <chat-id> "<message>"Message a worker
atox remove <chat-id>Stop a worker and delete its chat
atox send parent "<question>"Worker: ask the agent that started it
atox report "<summary>"Worker: send the result back

A few rules keep teams cheap and predictable:

  • Up to 4 workers per chat can run at the same time.
  • Workers can't start workers of their own.
  • Each worker reports once per task, so it can't flood your chat.
  • Workers start without trust or permission prompts: Atox trusts the project folder for them and allows the atox command only.
  • Messages wait until the agent can take them and never mix into what you're typing.

Spaces

Spaces group projects — for example work, side projects and clients. Switch spaces from the menu under New project or with ⌃1–⌃9. Each space remembers which project was open. From the same menu you can create, rename, recolor and delete spaces; projects of a deleted space move to another one.

Side by side

⌘-click a chat, or right-click it and choose Open to the Side, to see two chats of the same project at once. Drag the divider to resize. The layout is saved with the project.

Chat status

  • Pulsing — the agent is working.
  • Blue — it finished while you were elsewhere.
  • Gray — nothing new.

When a task takes longer than ten seconds and you're in another chat or app, Atox also sends a notification. Click it to jump to the chat.

Updates

Atox checks for new versions on its own. When one is ready, an Update button appears at the bottom of the sidebar — click it and Atox restarts on the new version. Running agents are stopped by the restart, so finish what they're doing first.

FAQ

macOS says Atox can't be opened

See First launch — it's a one-time step.

My agent isn't in the list

Atox looks for the agent's command in your shell. Make sure claude or codex works in Terminal, then restart Atox. If it lives somewhere unusual, set the full command in Settings → Agents.

Does Atox see my code or send it anywhere?

No. Atox only runs a terminal; your agent talks to its own service exactly as it does in Terminal. Atox itself has no accounts and no analytics.

Where is my data?

In ~/Library/Application Support/Atox. Removing a project from Atox never touches the folder on disk.

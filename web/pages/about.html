About Atox

The best coding agents live in the terminal. Claude Code and Codex are at their sharpest there — but once you run a few of them across a few projects, the terminal turns into a pile of tabs. Which window is working on what? Which one finished ten minutes ago and is waiting for you?

Atox is the answer to that pile. It is a Mac and Linux app with a sidebar of projects and chats, and every chat is a real terminal with an agent in it. You always see what is running, what is done and where.

Project goals

Atox isn't trying to be an IDE, and it doesn't replace your agent's interface. It is a calm place to run agents — nothing more.

  • Stay light. It should never be the reason your laptop is warm.
  • Stay out of the way. Your agent runs exactly as it does in the terminal, with its own commands, keys and settings.
  • Work with any agent. If it runs in a terminal, it runs in Atox.
  • Never lose context. Projects, chats and layouts are saved to disk the moment they change.

Under the hood

  • Each chat is a login shell in the project folder, started through a pseudo-terminal and drawn with xterm.js on the GPU.
  • Your projects and chats are stored in a single file on your computer: projects.json in ~/Library/Application Support/Atox on a Mac or ~/.config/Atox on Linux.
  • Agents talk to each other through the atox command over a local socket that only your user account can open.
  • No accounts and no analytics. The only request Atox makes on its own is checking GitHub for a new version.

Get started

Download Atox, open a project folder and start a chat with your agent. The download page also covers everything else, from shortcuts to agent teams.
